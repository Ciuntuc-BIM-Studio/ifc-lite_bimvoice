Structure profile library for civil works: `StructureProfile` (closed outline with holes, insertion origin, named anchors, material, colour and IFC class), eight parametric presets (cantilever and gravity retaining walls, box and arch tunnels, bridge deck slab, concrete safety barrier, kerb, lined ditch), validation, IFC4 class fall-backs and a JSON library format. The viewer keeps the library in the project file and edits it in Infrastructure › Profiles (preset parameters, or points dragged on a scaled drawing, origin and anchors), imports / exports library files, and makes a profile from a closed contour drawn on any view.
