A Project Navigator beside the model hierarchy lists the project's views and sheets: a floor plan per building level (merged across federated models), the four elevations, saved sections and 3D views, and numbered sheets. Opened views sit as tabs next to the 3D view in the centre; each tab keeps its own drawing, so switching is instant. Each view is configured with its work plane, cut plane and view depth. The project saves to a `.ifclite-project.json` file next to the IFC files and autosaves in the browser.
