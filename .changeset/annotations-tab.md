An Annotations ribbon tab for drawing tabs: text, leaders, aligned / linear / radius / diameter / angular dimensions, level marks (the plan's level, or the point's height on a section or elevation) and native CAD hatches. Hatches fill the closed region around a picked point, with islands, from drafted shapes or the drawing's cut outlines; twelve built-in patterns ship with the app and `.pat` files can be loaded into the project. Annotations select, move, copy, rotate, mirror, erase and undo like drafted geometry, and their text, height, dimension override, level value and hatch pattern / scale / angle are editable in the properties panel.
