Project versions. File › Save to version saves the project (as Save does) as a new numbered version with a name and a note; Update version saves it again into the current version, which keeps its number and name, what it held before kept as a revision; Version history lists the project's versions (date, size, note, the current one marked, what changed from the version before — models, drawings, views, sheets, standards, catalogues) to open or delete. Versions live in a content-addressed vault in the browser (parts shared between versions are stored once), the layout a data lake vault will reuse; a project file carries the version it was saved as. Also: a double click inside a roof's outline on the plan enters the roof as a block.
